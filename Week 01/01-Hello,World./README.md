| Standard Library | ชุดฟังก์ชันมาตรฐานที่ภาษา **C** เตรียมไว้ให้ใช้งาน


## 2. `int main(void)`
เป็นส่วนหัวของฟังก์ชัน **(main function)** ซึ่งเป็นจุดเริ่มต้นโปรแกรมภาษา **C** จะเริ่มทำงาน

### 🖇️ โครงสร้างของฟังก์ชัน `int main(void)`


### 2.1 `int`
หมายถึง ชนิดข้อมูลที่ฟังก์ชันจะส่งกลับ **(return type)**

- ต้องคืนค่าเป็นจำนวนเต็มให้ ระบบปฏิบัติการ **(operating system)** เพื่อบอกสถานะการทำงานของโปรแกรม
- `return 0;` คือ โปรแกรมทำงานสำเร็จ
- ค่าที่ไม่ใช่ 0 มันใช้บอกเกิดข้อผิดพลาด


### 2.2 `main`
หมายถึง ชื่อฟังก์ชันหลักของโปรแกรม

- ทุกโปรแกรมของภาษา **C** ต้องมี `main`
- ระบบปฏิบัติการจะเริ่มรันโปรแกรมที่ฟังก์ชันนี้ก่อน


### 2.3 `(void)`
หมายถึง พารามิเตอร์ **(input)** ของฟังก์ชัน

- `void` คือ ไม่รับพารามิเตอร์ใดๆ
- พารามิเตอร์ **(parameters)** คือ ตัวแปรที่ใช้รับข้อมูลเข้ามาในฟังก์ชัน

- - -

### 🧩 คำศัพท์ `int main(void)`
| คำศัพท์ | ความหมาย |
|------|-------|
| Main Function | ฟังก์ชันหลักของโปรแกรมและเป็นจุดเริ่มต้นการทำงาน
| Return Type | ชนิดข้อมูลที่ฟังก์ชันส่งค่ากลับ
| Return | การส่งค่ากลับจากฟังก์ชัน
| Input | ข้อมูลที่ส่งเข้าไปในฟังก์ชัน
| Parameters | ตัวแปรที่ใช้รับข้อมูลเข้ามาในฟังก์ชัน
| Operating System | ระบบปฏิบัติการของคอมพิวเตอร์
| Success | การทำงานสำเร็จ

- - -

### ⚙️ เจาะลึกในส่วน `int main(void)`

### 1. 🗜️ `int` - Return Type ของฟังก์ชัน `main`
📍 **ความหมายของ** `int` 

- `int` ย่อมาจาก **integer** แปลว่า จำนวนเต็ม

    + ใช้ระบุชนิดข้อมูลที่ฟังก์ชันจะคืนค่า กลับไปยัง ระบบปฏิบัติการ **(operating system)**
    + การคืนค่าเป็นจำนวนเต็ม ช่วยให้ระบบปฏิบัติการสามารถตรวจสอบสถานะการทำงานของโปรแกรมได้


📍 **การคืนค่า (Return Value)**

- `return 0;` โปรแกรมทำงานสำเร็จสมบูรณ์ **(success)**
- `return` ค่าที่ไม่ใช่ 0 มักจะเกิดข้อผิดพลาดหรือเงื่อนไขเฉพาะ **(error code)**
- ตัวเลขที่คืนค่าตัวอื่นๆ สามารถกำหนดได้ตามมาตรฐานหรือ **convention** ของโปรแกรมหรือระบบ เช่น
    + 1 = **generic error**
    + 2 = **file not found**
    + 3 = **invalid input**
    
❔ **ทำไมต้องคืนค่า**

- ระบบปฏิบัติการใช้ค่า **return value** เพื่อตัดสินใจ เช่น
    + เรียก **script** ต่อ
    + เก็บ **log**
    + ใช้ในการ **error handling** ของโปรแกรมอื่นที่เรียก `main`
- เป็นวิธีมาตรฐานในการสื่อสารระหว่างโปรแกรมเมอร์และ **OS**

- - -

🗺️ **รูปแบบทั่วไปของ** `main`

```
int main(void)
{
    //คำสั้งโปรแกรม
    return 0;
}
```

- `(void)` ไม่มีพารามิเตอร์เข้ามา
- ทุกๆคำสั่งในโปรแกรมจะถูกประมวลผลภายในบล็อก `{...}`
- การคืนค่า `return` เป็นขั้นตอนสุดท้ายของฟังก์ชัน


👀 **ข้อสังเกต**

- `int main()` จะสามารถใช้ได้ แต่ข้อมูลไม่ชัดเจนว่า ไม่มีพารามิเตอร์ **(implicit void)**
- `void main()` ไม่แนะนำ ถ้าเป็นตามมาตรฐานภาษา **C** เพราะมันไม่ได้คืนค่าให้ระบบปฏิบัติการ
- การใช้ `int main(void)` เป็นมาตรฐานภาษา C ที่ชัดเจนที่สุด
