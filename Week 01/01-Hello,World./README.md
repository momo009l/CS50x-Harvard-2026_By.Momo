# 🌎👋 Week 01 - Hello, World
โปรแกรมนี้จะแสดงข้อความ **"Hello, world"** บนหน้าจอ เป็นโปรแกรมภาษา **C** ถึงจะเป็นงานสั้นมาก แต่เป็นจุดเริ่มต้นของการเข้าใจ โครงสร้างและการทำงานของภาษา **C**

# 🔍 อธิบายโค้ดแต่ละส่วน
### 1. `#include <stdio.h>`
เป็นคำสั่งของคอมไพล์ **(preprocessor)** ใช้นำเข้า **header file** มาตรฐานที่เกี่ยวกับการรับ-ส่งข้อมูล **(standard input/output)** ซึ่งจำเป็นเพราะเราต้องใช้ฟังก์ชัน `printf()`


### 🤔 ทำไมจำเป็นต้องมีละ?
คำสั่ง `#include <stdio.h>` คือ การบอก **preprocessor** ให้นำ **header file** ที่ชื่อ `<stdio.h>` เข้ามาก่อนขั้นตอนการ **compile**

- `<stdio.h>` ย่อมาจาก **standard input/output header** ภายในไฟล์มีการประกาศฟังก์ชันอยู่ เช่น
    + `printf()` คือ แสดงผลออกหน้าจอ
    + `scanf()` คือ รับค่าจากผู้ใช้

- - -

### ❗ ถ้าไม่ใส่ แล้วใช้ `printf()` โปรแกรมจะเป็นยังไง?
- จะเกิด **error** หรือ **warning** ว่าเป็น **implicit declaration of function** เพราะคอมไพเลอร์ยังไม่รู้จักฟังก์ชันนั้น

เนื่องจากคอมไพเลอร์ยังไม่รู้ว่า `printf()` คืออะไร รับพารามิเตอร์แบบไหน คืนค่าอะไรประเภทไหนบ้าง?

- - -

### 🛫 ทำไมต้องอยู่ "บนสุดของไฟล์"?
บรรทัดที่ขึ้นต้นด้วย `#` เป็นคำสั่งของ **preprocessor** ลำดับการทำงาน คือ
- **preprocessor** ทำงานก่อน จัดการ `#include`,`#define`
- จากนั้นคอมไพเลอร์จึงเริ่มแปลโค้ดจริง

ดังนั้นต้องเขียน `#include` ไว้ก่อนการเรียกใช้ฟังก์ชันที่ประกาศอยู่ใน **header file**

- - -

### 📜 ความหมายของ `#include <stdio.h>`

| คำ | คำอ่าน | ความหมาย |
|------|-------|-------|
| `#` | แฮช | คำสั่งพิเศษของตัวแปลก่อนคอมไพล์ **(Preprocessor)** |
| `include` | อินคลูด | นำไฟล์อื่นเข้ามาใช้ |
| `<>` | เครื่องหมายมุม | ใช้กับไฟล์มาตรฐานของระบบ |
| `stdio` | เอส-ที-ดี-ไอ-โอ | ย่อจาก **Standard Input/Output** |
| `.h` | ดอทเอช | ไฟล์ประเภท **Header File** |

📌 **หมายเหตุ : `stdio` สามารถอ่านได้ 2 แบบ**

- เอส-ที-ดี-ไอ-โอ (อ่านทีละตัว คือ ทางการ)
- ส-ตี-โอ (อ่านรวบ คือ ใช้พูดทั่วไป)

- - -

### 🎯 หลักการทำงานของ `#include`
- `#include` เป็นคำสั่งที่ทำงานก่อนขั้นตอน **compile**
- ใช้ดึงเนื้อหา **header file** เข้ามาในโปรแกรม
- เพื่อให้เรียกใช้ฟังก์ชันที่ประกาศไว้ในไฟล์นั้นได้
- ถ้าไม่เขียน `#include` จะไม่สามารถใช้ `printf()` ได้และเกิด **error**

- - -

### 🧩 คำศัพท์พื้นฐาน `#include <stdio.h>`
| คำศัพท์ | ความหมาย |
|------|-------|
| Preprocessor | ตัวจัดการคำสั่งที่ขึ้นต้นด้วย `#` ก่อนการ **Compile**
| Compile | กระบวนการแปลโค้ดเป็นภาษาเครื่อง
| Compiler | โปรแกรมที่ทำหน้าที่แปลโค้ด
| Header File | ไฟล์ที่เก็บการประกาศฟังก์ชัน (มักมีนามสกุล `.h`)
| Warning | คำเตือน โปรแกรมยังรันได้แต่มีความเสี่ยง
| Error | ข้อผิดพลาด โปรแกรมรันไม่ได้
| Function | ชุดคำสั่งที่ทำงานเฉพาะ เช่น `printf()`
| Standard Library | ชุดฟังก์ชันมาตรฐานที่ภาษา **C** เตรียมไว้ให้ใช้งาน


## 2. `int main(void)`
เป็นส่วนหัวของฟังก์ชัน **(main function)** ซึ่งเป็นจุดเริ่มต้นโปรแกรมภาษา **C** จะเริ่มทำงาน

### 🖇️ โครงสร้างของฟังก์ชัน `int main(void)`

#### 2.1 `int` 

   คือ ชนิดข้อมูลที่ฟังก์ชันจะส่งกลับ **(return type)**

   เมื่อโปรแกรมทำงานเสร็จ ฟังก์ชัน `main` จะต้องคืนค่าเป็น "จำนวนเต็ม" กลับไปให้ระบบปฏิบัติการ **(operating system)** เพื่อบอกสถานะการทำงานของโปรแกรม

- `return 0;` หมายถึง โปรแกรมทำงานสำเร็จ **(success)**
- ค่าที่คืนไม่ใช่ 0 มักใช้เพื่อบอกว่าเกิดข้อผิดพลาด


#### 2.2 `main` 

   คือ ชื่อฟังก์ชันหลักของโปรแกรม
   
- ทุกโปรแกรมภาษา **C** ต้องมี `main` 
- ระบบปฏิบัติการจะเริ่มรันโปรแกรมที่ฟังก์ชันนี้ก่อนเสมอ


#### 2.3 `(void)` 

  คือ พารามิเตอร์ของฟังก์ชัน (ข้อมูลที่ฟังก์ชันรับเข้า)

- หมายถึง ฟังก์ชัน `main` ไม่รับพารามิเตอร์ใดๆ
- ในภาษา **C** การใส่ `void` ช่วยระบุชัดเจนว่าไม่มีพารามิเตอร์

📌 **พารามิเตอร์ (Parameter)** คือ ตัวแปรที่ใช้รับข้อมูลเข้ามาในฟังก์ชัน

### 📜 ความหมายของ `int main(void)`
| คำ | คำอ่าน | ความหมาย |
|------|-------|-------|
| `int` | อินท์ | ชนิดข้อมูล จำนวนเต็ม **(integer)** ใช้บอกว่าฟังก์ชันจะส่งค่ากลับเป็นจำนวนเต็ม
| `main` | เมน | ชื่อฟังก์ชันหลักของโปรแกรม เป็นจุดที่ภาษา **C** เริ่มทำงาน
| `()` | วงเล็บ | ใช้กำหนด พารามิเตอร์ของฟังก์ชัน
| `void` | วอยด์ | ไม่มีพารามิเตอร์หรือไม่มีข้อมูลที่ส่งเข้าฟังก์ชัน


### 🧩 คำศัพท์พื้นฐาน `int main(void)`
| คำศัพท์ | ความหมาย |
|------|-------|
| Main Function | ฟังก์ชันหลักของโปรแกรม
| Return Type | ชนิดข้อมูลที่ฟังก์ชันส่งค่ากลับ
| Operating System | ระบบปฏิบัติการของคอมพิวเตอร์
| Success | การทำงานสำเร็จ
| Parameter | ตัวแปรที่ใช้รับข้อมูลเข้ามาในฟังก์ชัน


## 3. `{}` บล็อคของฟังก์ชัน **(Function Body)**
เรียกว่า "เครื่องหมายปีกกา" ใช้กำหนดขอบเขตของคำสั่งในฟังก์ชัน

- `{` คือ จุดเริ่มต้นของบล็อคคำสั้ง
- `}` คือ จุดสิ้นสุดของบล็อคคำสั้ง

   คำสั่งทั้งหมดของ `main` ต้องอยู่ภายใน `{}`

⚙️ ตัวอย่าง

```
int main(void)
{
    printf("Hello, world\n");
}
```

- - -

### คำสั่งในโปรแกรม (statements)
คำสั้งในภาษา **C** ต้องจบด้วย `;`

⚙️ ตัวอย่าง

```
printf("Hello, world\n");
return 0;
```

- `;` เรียกว่า **semicolon**
- ใช้บอกว่า คำสั่งจบแล้ว


### 4. `return 0;`
หมายถึง
- ส่งค่า 0 กลับไปให้ **operating system**
- แสดงว่าโปรแกรมทำงานสำเร็จ

⚙️ ตัวอย่าง

```
return 0;
```
